# Cuprea

A Zen factory game in your browser: belts, machines, and little bots you program yourself.

**Play:** https://noice787965-droid.github.io/cuprea/play/

This repository is the published website (GitHub Pages): the landing page (`index.html`), the privacy
and terms page (`privacy.html`) and the built game under `play/`. These are minified build files;
the source is kept by the developer. Saves stay in the player's own browser; the game sends nothing anywhere.
