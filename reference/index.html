Bot commands

From level 6 a Bot Bay holds one bot you program with one command per line. Bots fly over everything, so they can stock machines, empty depots and run outposts.

CommandWhat it does
goto x yfly to a tile (bots fly over everything)
goto hub / goto homefly to the hub, or back to this bay
goto nearest depotfly to the closest building of a type (depot, assembler, furnace, extractor, …)
fill item|anykeep taking from the building below until the bot is full
empty [item|all]keep dropping into the building below until the bot is empty
set name 0 / add name 1store a number in a variable (add can be negative)
if name >= 10 jump labelcheck a variable
take item [n]pick up from the building below: hub, depot, a machine's output, an extractor
take any [n]pick up whatever is there
take wire 4 / take gear 2several takes in a row carry a mix; the cargo limit counts every kind together. The panel shows what the bot holds and why a line did nothing
drop [item|all] [n]put cargo into the building below: hub, depot, a machine's input, trash
wait secondspause
name:a label to jump to
jump namecontinue from a label
if carrying < 5 jump namejump when the cargo count matches (< > <= >= = !=)
if hub item > 50 jump namecheck hub storage
if here item = 0 jump namecheck the building below (use any for all items)
stopend the program

Example programs (the same ones the Bot Bay offers)

Stock a machine

# Keep a machine stocked from the hub.
# Change 5 3 to your machine's tile (hover it to see x y).
goto hub
take iron_plate 20
goto 5 3
drop all
wait 5

Outpost ferry

# Bring everything from a remote depot back to the hub.
# Change 40 12 to your depot's tile.
start:
goto 40 12
take any
if carrying = 0 jump idle
goto hub
drop all
jump start
idle:
wait 5
jump start

Nearest depot run

# Fill up at the closest depot, unload at the hub, count the trips.
set trips 0
start:
goto nearest depot
fill any
goto hub
empty
add trips 1
if trips < 100 jump start
stop

Collect output

# Collect finished parts from a machine and deliver them.
# Change 8 2 to your machine's tile.
start:
goto 8 2
take any
if carrying < 10 jump start
goto hub
drop all
