Cuprea Play

Privacy & terms

Applies to this website and the Cuprea web game it hosts. Last updated 2026-10-07.

The short version

The game runs entirely in your browser. It has no accounts, no chat and no advertising trackers. Your factory is saved on your device. The only thing that happens on its own is an anonymous visit count (a cookie-free counter, described below, with an off switch in Settings); everything else leaves your device only when you press a button that says so, including the optional Sync that carries a profile to your other devices under a secret code.

What the game stores on your device

  • Your worlds (one per profile), settings, saved blueprints, Daily Factory results and any bug-report notes you write, in your browser's local storage. They stay on this device and in this browser.
  • Clearing site data, using a private window, or some browsers after a long time without a visit (Safari) can remove them. Settings → Export saves a backup file; Import restores it.
  • An offline copy of the game's own files (the page, its code and icons), so the game can open without a connection and be added to your home screen. It holds nothing about you; clearing site data removes it too.

What we receive from you

  • Anonymous usage counts. This website and the game use Umami, a cookie-free counter, to tally page views, where visitors came from (the referring site), country, browser, device and screen type, and a few named milestones such as "level 3 reached", "Play now clicked", "Join the Discord clicked" or a tap on "How was level 2?". It sets no cookies and stores no name, account, device ID or IP address: a hashed, regularly rotated value tells visits apart, and the raw address is not kept. We use it to see where players get stuck and what to build next; it is never used for advertising. Settings → Share anonymous usage counts in the game turns it off for this site too, and the counter honours your browser's Do Not Track and Global Privacy Control signals. Copies of the game on other sites or opened from a file count nothing.
  • Everything else only when you press a button. The game does not otherwise phone home; every send below happens only when you ask.
  • Play stats, only if you press "Send play stats" (in Stats). That sends an anonymous summary: levels completed, time played, machine counts, settings, screen size, browser name and game version. It contains no name, email, account, advertising ID or device ID, and the server does not store IP addresses or user agents. It is used to see where players get stuck and to decide what to build next.
  • Your world, only if you turn on Sync for a profile (in Profiles). Sync keeps one profile the same on your laptop and your phone. The game stores that profile's save (the world, your blueprints and the profile's name) on our sync server under a random 16-letter secret code that only your devices know; the server keeps a hash of the code, not the code itself, and no account, email, name or IP address. Any device that types the code gets the world, so keep the code to yourself. "Stop on this device" leaves the server copy alone, "Delete from server" removes it, and saves nobody has opened for a year are deleted automatically. The server runs on Cloudflare Workers (Cloudflare's privacy policy); like any website it sees your IP address while handling a request; our server code does not store it. Profiles without Sync never leave your device.
  • Bug reports, only if you press "Send report" (in Settings → Bug report & comments, or "Send error report" on the error bar). That sends exactly the text shown in the report: your message, the game version and, if you tick the boxes, the same anonymous play stats as above and your world save. It travels through a form-to-email relay (Web3Forms) to our inbox; like any website, the relay sees your IP address while it receives the report, under its own privacy policy. We keep reports only to fix the bug or weigh the idea. If this copy of the game has no Send button, the report is plain text for you to copy or save, and nothing is sent. Please do not include personal information in reports.

Advertising on this website

This version of the website shows no advertisements. The rest of this section describes what would apply if one is ever added. On wide screens the website would show one advertisement beside the game, served by Google AdSense. We request non-personalised ads. Third-party vendors, including Google, use cookies or similar technologies to serve ads based on your visits to this and other websites, and Google may process your IP address and browser information. You can read how Google uses information from sites that use its services at policies.google.com/technologies/partner-sites and manage ad personalisation at adssettings.google.com. Where the law requires it, a consent message is shown before any ad is loaded.

The game page on itch.io and the downloadable version show no ads.

Links to other services

The game and this website link to our Discord server. Discord is a separate service with its own privacy policy and requires users to be 13 or older; nothing is shared with Discord by visiting this site or playing the game. The link is optional and the game never needs it.

Children

The game is for a general audience and asks for no personal information from anyone, of any age. The usage counts above are aggregate numbers used only to run and improve the game (no profiles, no advertising), and we do not knowingly collect personal information from children. If you believe a child has sent us personal information (for example inside a bug report), contact us and we will delete it.
